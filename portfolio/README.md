## ⚙️ Cara Menjalankan

1. **Clone / download** project ini
2. Pastikan file `assets/images/profile.jpg` sudah ada
3. Buka dengan **VS Code Live Server** (`Go Live`)  
   atau buka `index.html` langsung di browser

> ⚠️ Karena menggunakan Google Fonts & Font Awesome melalui CDN,
> koneksi internet diperlukan untuk tampilan optimal.

---

## 🔗 Memperbarui Link Project

Cari `data-placeholder="true"` di `index.html` dan ganti atribut `href="#"` 
dengan URL Demo atau GitHub yang sebenarnya.

```html
<!-- Sebelum (placeholder) -->
<a href="#" class="btn btn--outline btn--sm project-card__btn" data-placeholder="true">

<!-- Sesudah (aktif) -->
<a href="https://your-demo-link.com" class="btn btn--outline btn--sm">
```

Hapus atribut `data-placeholder="true"` agar tombol aktif kembali.
